# 🎯 Logo Lab

**Vector constructor of the DCreator brand mark — palettes, avatar containers, gradients, glow, and SVG/PNG export.**

Векторный конструктор фирменного знака DCreator — палитры, подложки-аватары, градиенты, свечение и экспорт в SVG/PNG.

---

## 🇺🇸 About
Logo Lab is the tool I used to design the DCreator logo you see across all my profiles. It lets you tweak the D-mark shape, arrow angle, gradient, glow, and avatar container — then export a clean SVG that stays sharp at any size.

## 🇷🇺 О проекте
Logo Lab — инструмент, с помощью которого я разработал логотип DCreator, который ты видишь на всех моих профилях. Позволяет настраивать форму знака D, угол стрелы, градиент, свечение и контейнер-аватар, а затем экспортировать чистый SVG, который остаётся чётким на любом размере.

---

## ✨ Features / Возможности

- 🔷 **4 mark variants** — classic, monolith, duo, outline
- 🎨 **6 brand palettes** — navy, aurora, acid, sunset, emerald, mono
- 🔵 **Avatar containers** — circle, squircle, hexagon
- ✨ **Live glow & gradient** — настраиваемое свечение и угол градиента
- 📐 **Precise controls** — slant, weight, roundness, arrow size
- 📤 **SVG + PNG export** — вектор и растр до 4096px
- 💾 **Presets** — сохраняй и загружай свои варианты
